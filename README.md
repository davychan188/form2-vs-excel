# Form 2 vs Excel 對比工具

用嚟對比 **Form 2 Tree Risk Assessment PDF** 同 **Excel Tree Inventory** 報表嘅瀏覽器工具。

## 功能

- 上傳一份 Excel Tree Inventory，以及多份 Form 2 PDF
- 用 **Tree ID** 自動配對
- 對比以下欄位：
  - **Height**（樹高）
  - **Crown Spread**（樹冠闊度）
  - **Aggregated DBH**（合計胸徑）
- 高亮顯示兩邊數值唔一致嘅項目

## 點用

1. 用瀏覽器開啟本頁（或下載 `Form2_vs_Excel_Compare.html` 本地開啟）
2. 上傳 Excel 報表
3. 上傳一份或多份 Form 2 PDF
4. 工具會按 Tree ID 配對並顯示差異
